## 阅读约定

- 文档中 `[推荐]` 表示我方按最佳实践确定、可直接开发；`[待确认]` 残留极少。
- 界面文案：中文默认、英文可选（i18n）；品牌统一取 `packages/shared/src/brand.ts`。
- **禁用词**：金币、充值、提现、现金、红包、奖池、开奖、押注（英文 Coins / Cash / Withdraw / Bet / Prize Pool），统一用「积分 / 名次奖励 / 积分榜」。
- 01/02/05/06 中涉及「金币、充值、提现」的段落均为历史设计，现行规则以 07 为准。
