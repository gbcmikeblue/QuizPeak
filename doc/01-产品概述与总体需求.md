# 01 · 产品概述与总体需求

## 1. 产品定位

**知巅（QuizPeak）** 是一个「知识答题 + 竞赛排名 + 积分激励」的在线答题平台。

核心玩法：

1. 用户注册后浏览题库（Quiz），按分类/难度参与答题，获得分数、XP、积分。
2. 平台定期开设 Contest（限时竞赛）：固定开始/结束时间、固定题数、报名消耗积分（或免费）、名次奖励与积分榜，按得分与用时排名。
3. 积分只用于站内答题与竞赛消耗，来源为签到、看广告、给上榜选手点赞、活动奖励等**行为激励，不涉及任何货币**。
4. 通过邀请好友（referral）、每日连续登录（streak）、徽章（Badges）、排行榜（Leaderboard）形成增长与留存闭环。
5. 内容运营侧通过文章（Blog & Articles）做 SEO 与用户教育。

一句话：**答题赢奖励的知识竞技平台，前端 Web + H5 + 小程序三端，后端含完整运营管理后台。**

## 4. 核心业务流程

### 4.1 普通 Quiz 流程

```
浏览列表/搜索/分类筛选 → 卡片 View Details（详情页）→ Start Quiz / Play Now
  → 答题（单题 120s 倒计时，单选/多选/判断/填空）→ Submit / Continue → 交卷
  → 结果页（正确率、对错数、用时、Preview Answers 逐题解析）
  → 记录写入 History；关卡进度与解锁状态回写卡片
```

要点（截图可见）：
- Quiz 卡片有「Enrolled Fee：Free / N coins」与「Enrolled」状态两种形态，说明**付费 Quiz 需先消耗积分解锁**才可 `Play Now`。
- Quiz 有 `N Levels` 概念，卡片上以「圆点进度」表示已完成的关卡。
- 难度分 `Beginner / Intermediate / Advanced`（绿/蓝/红徽章）。

### 4.2 Contest 流程

```
首页 Current Contests / Contest 列表 → Contest 详情（Overview / Leaderboard / Prizes）
  → 点「Unlock Now」→ 弹窗「Start Your Contest」确认（题数、所需积分、可用积分、已报名人数）
  → 确认扣除积分 → 进入答题（Q: x/N，单题倒计时）→ 逐题 Submit/Continue
  → 交卷 → 进入 Leaderboard 排名（Score + Time）
  → 竞赛结束后按排名发奖（积分 + XP），写入积分流水 / 通知
```

要点（截图可见）：
- 一场 Contest 有：封面、标题、总时长（16:00）、题数（8）、开始/结束日期、分类、参赛消耗积分、名额（Spots Filled 22/609）、名次奖励（前三名 1000/500/100 积分，对应 10000/5000/1000 XP）。
- 竞赛状态：`Running`（进行中）、`Upcoming`（未开始）、`Completed`（已结束）`[待确认命名]`。
- 报名后按钮由 `Unlock Now` 变为 `Start Playing`，名额进度实时增长。
- Leaderboard 列：Rank / Player（头像+昵称）/ Score / Time（mm:ss），有分页。

### 4.3 积分流（无货币）

```
获取：新人礼（+100）｜每日签到（+10 起，连续递增）｜看广告（+10，每日 5 次）
      ｜给上榜选手点赞（+5，每日 5 次）｜活动奖励｜答题/竞赛名次奖励｜邀请好友（+100）
消耗：解锁付费 Quiz、竞赛报名、Hint 提示
说明：无充值、无提现、无任何货币或等价物，积分不可转让
```

**规则要点（全部后台可配，详见 `07-积分体系与品牌规范.md`）**
- 积分只用于站内答题与竞赛消耗，**系统内不存在支付、订单、提现相关表与页面**。
- 积分不足时统一提示「积分不足」，引导进入「赚积分」页完成任务。
- 所有积分变动写流水（类型 + 业务来源 + 变动后余额），业务来源唯一键保证幂等。
- 原站的金币（Coins）、Bkash 提现、充值套餐等设计**全部作废**，仅作为 UI 参考保留在历史文档中。

### 4.4 邀请裂变流程

```
个人中心 Invite Friends → 获得专属链接 https://<域名>/sign-up?referer=<username>
  → 分享 → 好友通过链接注册（绑定邀请关系）→ 好友通过首个关卡后，邀请人 +100 积分
```

### 4.5 客服工单流程

```
Support Tickets 列表 → Create Ticket（Subject / Priority / 描述 / 附件）→ Submit
  → 列表显示状态（Open…）与优先级（High / Medium / Low）
  → 进入详情：查看描述与附件、Replies 对话、继续回复（可带附件）
  → 后台客服回复 → 状态流转 Open → In Progress → Closed [待确认]
```

## 6. 全局 UI 与交互规范（从截图归纳）

1. **设计语言**：主色深绿 `#0E8A52` 系（按钮、进度条、激活态），辅助色米黄 `#F5EFD9` / 浅绿背景 `#EAF4EE`，警示红（Cancel、负值金币）、橙色（Withdraw、View Details、XP 徽章）。
2. **导航**：顶部居中胶囊导航（答题 / 竞赛 / 文章 / 小游戏 ▾ / …），右侧依次为通知铃铛（有未读时绿点）、积分胶囊（星标 + 数字，点击进「赚积分」）、头像（下拉：个人中心 / 设置 / 退出登录）。
3. **页脚**：Logo + 5 个社交图标、Quick Links（Confidentiality & Privacy / Legal Information）、Resources（About Us / Contact / Privacy Policy）、Contact（电话 / 邮箱 / 地图）、版权行（`Copyright @ 2026 All rights reserved. 知巅`）与语言切换（English）。
4. **卡片化**：所有列表用圆角卡片，图标 + 数字的信息条（时间、题数）统一为灰色小字。
5. **进度可视化**：名额、等级、关卡、答题进度、每题倒计时均用进度条或环形指示。
6. **空态**：统一「插图 + 主标题 + 副标题」，如 `No Favorites Found`、`No Notifications`、`No deposits found`、`No withdraw found`。
7. **表单**：必填项标题后带红色 `*`，文本域带字数计数（`0/1000`），密码框带显示/隐藏眼睛图标。
8. **表格化列表**：工单、积分流水、活动领取记录、排行榜均使用带浅绿表头的表格，状态用彩色胶囊标签。
9. **响应式**：截图仅桌面版；H5/小程序布局需另行提供（见 04 篇）。

## 7. 非功能需求

| 分类 | 要求 |
| --- | --- |
| 性能 | 列表页首屏 < 2s；答题页切题 < 300ms；图片走 CDN + 懒加载 |
| 兼容 | PC 端 Chrome/Edge/Safari 最新两个大版本；H5 适配 iOS Safari 与 Android Chrome；小程序按平台要求 |
| 多语言 | 原界面英文 + Footer 语言切换。**已确认走 i18n**：默认简体中文，提供英文，语言包 JSON 共用（PC/H5/小程序/后台同一份 key） |
| 经济模型 | 纯站内积分：无充值、无支付、无提现、无现金等价物（详见 `07-积分体系与品牌规范.md`） |
| 广告 | 激励视频需对接合规广告平台（优量汇 / 穿山甲），服务端校验回调后发放积分 |
| 时区 | 统一 `Asia/Shanghai (UTC+8)`；日期格式中文 `YYYY-MM-DD`、英文 `DD MMM, YYYY` |
| 安全 | 密码加密存储、2FA 开关、答题防作弊（禁止刷新重答、单题时长服务端校验）、积分发放需幂等与频控 |
| 一致性 | 答题计分、排名、奖励发放必须在服务端完成，前端只做展示 |
| 审计 | 积分变动、积分任务配置、后台操作需留审计日志 |
| 数据 | 答题记录、积分流水、工单永久可查；排行榜按月/总榜区分 |
| 可观测 | 关键链路（积分发放、广告回调、竞赛开赛、发奖）需日志与告警 |
