**右侧信息卡**

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| Category | `Programming` | 分类 |

- 10 个关卡为**独立题库**，每关 8 题（单场题数后台可配）；详情页 `Questions` 显示本关题数，关卡数单独展示。源站「详情 10 questions / 答题页 Q:1/8」不一致，按本规则修正。

### 3.4 Quiz 答题页

截图：`补充/B3-Quiz 答题页.png`（判断题）、`补充/B4-Quiz 答题页 - 已选答案.png`（单选已选）

布局：浅绿整页背景 + 居中内容区，**无导航栏与页脚**，仅顶部居中 Logo。

| 元素 | 需求 |
| --- | --- |
| 进度条 | 顶部通栏细进度条，宽度 = 已答题数/总题数 |
| 题号 | 右侧白底胶囊 `Q: 1 / 8` |
| Cancel | 右侧红色按钮，二次确认后退出（本次作答作废） |
| 题干 | 左对齐，支持长文本、填空下划线、富文本 |
| 题型提示 | 多选题显示绿色提示 `Answer can be one or more.`（单选/判断不显示） |
| 选项 | 居中列表，每行 `[控件] [序号] [选项文本]`，整行可点 |
| 选中态 | 绿色实心单选点 + 边框变绿 + 底色浅绿 |
| 圆形倒计时 | 左下环形进度 + 秒数（`01:58` → `00:00`），**单题 120 秒** |
| Hint | 左下 `Hint` 按钮（灯泡图标） |
| Skip | 静音喇叭图标，跳过本题 |
| Submit | 绿色按钮，提交当前题 |
| Continue | 米黄色按钮，进入下一题（未作答按错处理） |

**规则（已决策）**
- **单题时长 120 秒**；超时自动进入下一题并按错误计分，最后一题超时直接交卷。
- 提交后立即判分并播放反馈动效（`B4` 可见撒花）；`Submit` 置灰、`Continue` 变橙色高亮。
- `Hint`：每场免费 1 次，超出消耗 10 金币（后台可配），展示解析首句或排除一个错误项 `[推荐]`。
- `Skip`：每场最多 3 次（后台可配），跳过按错误计分。
- 多选题**全对才得分**（后台可切换部分给分）。
- 断线/刷新：服务端保存已答题目与剩余秒数，重进从当前题继续；同一 Attempt 不可重开。
- 每题实时上报（`POST /attempts/{id}/answers`），交卷写 History 与 XP/金币。

**规则（已决策）**
- **单题 120 秒**（与 Quiz 一致，采用同一答题组件）；详情页时长 = 题数 × 120s（如 8 题 → `16:00`）。单题超时自动进入下一题并按错误计分，最后一题超时直接交卷。
- 每题答案实时上报；断网/刷新按 Attempt 恢复（已答题 + 剩余秒数）。
- 得分规则：每题等分（100/题数），用时用于同分排名比较（Leaderboard 的 `Time`）。
- 多选题全对得分（后台可配置部分给分）。
- 交卷后不可修改，立即进入 Leaderboard（Score + Time）。

### 4.6 赛后结算

- 竞赛 End Date 到达后由后台定时任务锁定排名并结算：按名次发 Coins + XP，写 Coin History 与站内通知。
- 并列规则（推荐）：同分则比用时（短者优先）；分数与用时都相同则并列同名次，奖励按名次顺延（如两人并列第 1，则下一人为第 3）。
- 发奖改为「结束即发」，不需要用户手动领取；发奖失败进重试队列并在后台标红。
- 用户侧入口：`History → Contest` Tab（`C9` 印证 Tab 设计），行内显示竞赛名、日期、得分、名次与奖励。

## M14 通用交互与状态规范

1. **加载**：列表/详情必须有骨架屏或 Loading；按钮提交中禁用并显示 loading。
2. **空态**：插图 + 主文案 + 副文案（参考 M7.3/M7.4/M8.2/M8.3）。
3. **错误**：网络异常提示 + 重试按钮；表单错误定位到字段并红字提示。
4. **确认**：取消答题、清空通知、提现提交、退出登录均需二次确认弹窗。
5. **Toast**：成功/失败轻提示（右下或顶部）。
6. **面包屑**：静态内容页（About/Top Players/Contact/文章详情）展示 `HOME » xxx`。
7. **分页**：列表统一 `« 1 2 … N »`，P2 起可省略号折叠。
8. **响应式断点**：≥1200px 三列、768~1199px 两列、<768px 单列（依据截图布局推断）。
9. **权限**：所有写操作需登录；管理接口需鉴权。
