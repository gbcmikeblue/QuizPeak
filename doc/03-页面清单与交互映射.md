## 2. 关键跳转关系

```
首页 ┬─ View Contest ───────────────► Contest 详情(Overview)
     ├─ 分类 chip / 搜索 ──────────► Quiz 列表(带筛选参数)
     ├─ Contest 卡片 ─────────────► Contest 详情
     └─ Contest 卡片 Start Playing ─► Contest 答题页

Quiz 列表 ┬─ Start Quiz（免费）────► Quiz 答题页
          ├─ Start Quiz（付费）────► 支付/确认弹窗 ──► Quiz 答题页
          ├─ Play Now ────────────► Quiz 答题页（续答）
          ├─ View Details ────────► Quiz 详情 ──► Quiz 答题页
          └─ ♥ ───────────────────► Favorites（数据写入，不跳转）

Contest 详情 ┬─ Unlock Now ────────► 报名确认弹窗 ──Unlock Now──► 答题页
             ├─ Start Playing ─────► 答题页
             ├─ Tab 切换 ──────────► 同页内容切换（URL query 同步）
             ├─ View Rules & Terms ► 规则弹窗
             └─ 分享 ──────────────► 分享弹窗

答题页 ┬─ Cancel ─────────────────► 二次确认 ──► 返回详情
       ├─ Submit/Continue ───────► 下一题 ──最后一题──► 结果页
       └─ 倒计时结束 ─────────────► 自动交卷 ──► 结果页

Header ┬─ 金币余额 ───────────────► Buy Coins
       ├─ 铃铛 ───────────────────► 通知面板 / Notifications 页
       └─ 头像 ───────────────────► Profile / Settings / Sign Out

Dashboard 侧栏 ┬─ Profile/History/Favorites/... ──► 对应子页（保持侧栏）
               ├─ Support Tickets ──► 列表 ──► 新建 / 详情
               ├─ Withdraw ─────────► 钱包页 ──► 提现表单（Bank/Bkash）──► 返回钱包
               └─ Invite Friends ───► 复制链接 / 分享

About Us ┬─ Contact Us ──► Contact
         └─ View All ────► Top Players
文章列表 ── 分类/标签 ──► 列表(筛选) ； 卡片 ──► 文章详情 ── Back to Blog ──► 列表
Footer ── Quick Links / Resources / Contact / 地图 外链
```

## 3. 交互细节清单

| 交互 | 位置 | 要求 |
| --- | --- | --- |
| Tab 切换 | Contest 详情 | 内容区切换，URL 同步 `?tab=`，支持直接访问 |
| Tab 切换 | History / Favorites | `Quiz` / `Contest` 两个 Tab，切换不刷新页面 |
| 收藏 toggle | 所有 Quiz/Contest 卡片 | 乐观更新 + 失败回滚；未登录跳登录 |
| 名额进度 | Contest 卡片/详情 | 数字 + 进度条；报名成功后即时 +1 |
| 分页 | 首页比赛区块 | `« 1 2 … N »`，页面滚动保持位置 |
| 密码可见切换 | 设置/登录 | 眼睛图标切换 `type=password/text` |
| 字数计数 | 工单描述 | `0/1000` 实时更新，超限禁止输入 |
| 下拉联动 | 提现方式 | 选择不同方式切换表单字段（Bank 5 项 / Bkash 1 项），切换时清空已填的对方字段 |
| 复制链接 | 邀请好友 | 点击复制图标 → 复制成功 toast |
| 手风琴 | About → FAQ | 单开模式，默认展开第一项 |
| 轮播 | About → 用户评价 | 左右箭头切换，桌面 3 张/屏，可循环 |
| 通知清空 | Notifications | `Clear All` → 二次确认 → 列表空态 |
| 二次确认 | 答题 Cancel、提现提交、退出登录、删除收藏 | 统一确认弹窗组件 |
| 状态胶囊 | 工单/订单/提现 | `Open`(绿)、`In Progress`(橙)、`Closed`(灰)、`Success`(绿)、`Failed`(红)、`Pending`(橙) |

## 4. UI 规范要点（供设计/前端还原）

| 项 | 值（截图取样，可微调） |
| --- | --- |
| 主色（深绿） | `#0E8A52` 附近；按钮圆角 6~8px |
| 深绿 hover | 加深约 10% |
| 页面背景 | `#FFFFFF`；卡片/内容区浅绿底 `#EAF4EE` ~ `#F0F7F2` |
| 提示/横幅底 | 浅米黄 `#FDF8E7`（如 Prize Pool / Entry Fee 小块） |
| 危险色 | `#E5484D`（Cancel 按钮、负值金额、High 优先级） |
| 强调橙 | `#F5A623`（Withdraw、View Details、XP 胶囊） |
| 文字 | 主 `#1A1A1A`，次 `#6B7280`，禁用 `#9CA3AF` |
| 字体 | 无衬线（截图近似 Poppins/Inter 类），标题加粗 700，正文 400 |
| 圆角 | 卡片 10~12px，按钮 6~8px，胶囊 999px |
| 间距 | 容器最大宽约 1120~1200px，左右留白 16~24px，卡片间距 16~24px |
| 阴影 | 卡片极轻阴影或无阴影，靠背景色区分层次 |
| 图标 | 线性图标（约 1.5~2px 描边），与文字同色 |
| 头像 | 圆形；无头像时用首字母 + 主题色底 |
| 表格 | 表头浅绿底 `#DCEFE4`，行斑马纹，行高约 44~56px |
