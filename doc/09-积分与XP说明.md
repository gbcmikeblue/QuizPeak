# 积分与 XP 说明

> 面向运营、测试与新同事：讲清「积分」和「XP」这两个数字分别是什么、怎么增长、排行榜按哪个排。
> 版本：2026-10-23（对应代码 `server/src/attempts/attempts.service.ts`、`server/src/contests/contests.service.ts`、`server/src/leaderboard/leaderboard.service.ts`）

## 1. 一句话区分

| 名称 | 含义 | 变化方向 | 用途 |
| --- | --- | --- | --- |
| **积分（points）** | 站内「钱」 | 可增可减 | 解锁题库、报名竞赛、Hint 提示；也可作为月榜指标 |
| **XP（经验值）** | 站内「成就值」 | **只增不减** | 决定总榜排名；设计上用于等级提升 |

两者都不可兑换任何货币，也不可转让。

## 2. XP 怎么来

| 来源 | 规则 | 代码位置 |
| --- | --- | --- |
| 答题 | **每答对 1 题 +10 XP**，且仅在**首次通关**该关卡时发放（重复刷同一关不再加 XP） | `attempts.service.ts` → `finish()`：`xpEarned = correct.length * 10` |
| 竞赛名次 | 按后台配置的奖品发放，例如第 1 名 +10000 XP、第 2 名 +5000、第 3 名 +1000 | `contests.service.ts` → `settle()` |
| 其他 | 目前没有签到/点赞/看广告的 XP（这些只发积分） | — |

举例：一关 8 题全对、首次通关 → **+80 XP**；同一关再玩一次满分 → **+0 XP**（只发积分奖励）。

## 3. 积分怎么来（对比参考）

| 来源 | 额度（后台可改） |
| --- | --- |
| 新人礼 | +100（注册一次） |
| 每日签到 | +10 起，连续签到每日 +2，递增封顶 +20 |
| 看广告 | +10 / 次，每日 5 次 |
| 给上榜选手点赞 | +5 / 次，每日 5 次（同一人每日 1 次） |
| 活动 | 按活动配置，每人每活动 1 次 |
| 答题奖励 | 首次通关按正确率发积分（与 XP 同时发） |
| 竞赛名次 | 按后台配置（如 1000/500/100） |
| 邀请好友 | 被邀请人首次通关后，邀请人 +100 |

消耗：解锁付费题库（7 天有效）、竞赛报名、Hint（首次免费后 10 积分/次）。

## 4. 排行榜口径

| 榜单 | 排序依据 | 说明 |
| --- | --- | --- |
| **总榜（period=all）** | `user.xp` 降序 | 反映历史累计答题与竞赛成绩，终身不重置 |
| **月榜（period=month）** | 当月**获得的积分**合计（排除后台调整类流水） | 每月 1 日 00:00 自然重置，可反映近期活跃度 |

同分排序：先比 XP（月榜比积分），再比平均正确率，最后比答题场次。

> 注意：总榜看 XP、月榜看积分，所以同一个人两个榜的名次可能完全不同。测试账号「测试选手」月榜第 1、总榜第 4 就是这种情况。

## 5. ⚠️ 等级（Level）当前是占位

- 用户表有 `level` 字段，默认 `1`，注册后不再变化
- **代码里没有自动升级逻辑**，也没有等级阈值表
- 界面展示的 `Lv.1` 是真实字段值，不是根据 XP 算出来的

## 6. 常见问题

**Q：为什么我满分了只加 80 XP，别人加 10000？**
A：80 XP 是答题（8 题 × 10）。10000 是竞赛第 1 名的名次奖励，两者不是一个量级，这是设计上刻意的——竞赛是主要成就来源。

**Q：积分花掉会影响排名吗？**
A：总榜不影响（看 XP，只增不减）；月榜影响（看「获得」的积分，消耗不减当月已获得的积分，因此花积分不会让月榜名次下降）。

**Q：XP 会减少吗？**
A：不会。目前没有任何扣 XP 的逻辑，后台调积分也只改积分不动 XP。

**Q：被点赞多的人总榜会更高吗？**
A：不会。点赞只给点赞者发积分、给被赞者增加 `likesReceived`（人气值），不影响 XP 与排名。

**Q：哪里能看到自己的 XP？**
A：个人中心顶部资料卡（`Lv.x` 旁的数值）、排行榜表格的「XP」列，或 `GET /api/me` 的 `xp` 字段。

## 7. 相关接口

| 接口 | 返回 |
| --- | --- |
| `GET /api/me` | `points`、`xp`、`level`、`totalEarned`、`likesReceived` |
| `GET /api/leaderboard?period=all\|month` | 榜单列表（rank / nickname / avatar / xp / metric / quizzes / avgRate） |
| `GET /api/leaderboard/me` | 我的两个榜名次与总人数 |
| `GET /api/points/summary` | 积分余额、今日所得、签到状态、任务进度 |
| `GET /api/points/transactions` | 积分流水（含类型、变动值、变动后余额） |
