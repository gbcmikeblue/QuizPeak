## A. 认证模块补充

### A3 · 验证码校验页（注册后 / 忘记密码）

**布局**：左侧表单区（同 `A1/A2` 左栏宽度与边距）+ 右侧插画。

| 元素 | 规格 |
| --- | --- |
| 标题 | `Verify your phone` / `Verify your email` |
| 说明 | `We sent a 6-digit code to 138****8888` |
| 验证码输入 | 6 个独立方格（自动聚焦下一格，支持粘贴整串） |
| 主按钮 | `Verify`（未填满 6 位时置灰） |
| 重发 | `Resend code in 58s` → 倒计时结束后变 `Resend`；60 秒内不可点 |
| 换绑 | `Wrong number? Change` 返回上一步 |
| 错误态 | 验证码错误 → 输入框全红 + `Invalid code, 2 attempts left`；5 次失败锁定 10 分钟 |

**规则**：验证码 5 分钟有效、一次性；验证成功 → 注册场景直接登录并跳首页（弹「注册成功 +100 金币」toast），找回密码场景 → 跳 A5。

### A5 · 重置密码页

| 元素 | 规格 |
| --- | --- |
| 标题 | `Set new password` |
| 新密码 | 输入框 + 眼睛图标 + 强度条（弱/中/强） |
| 确认密码 | 同上，实时校验是否一致（不一致右侧红字 `Passwords do not match`） |
| 规则提示 | `At least 8 characters, including letters and numbers` |
| 主按钮 | `Reset password` |
| 成功 | 自动登录并跳首页；同时把该账号其他端强制下线 |

### A6 · 未登录拦截

- 非弹窗，直接跳 `/login?redirect=<encodeURIComponent(当前路由)>`；登录后回跳。
- 首页/列表/文章/About 可匿名浏览；答题页、个人中心、钱包、工单未登录直接重定向。
- 收藏、报名按钮在未登录时仍可点，点击后跳登录（登录成功回来再执行原动作 `[推荐]`，用一个 `pendingAction` 标记）。

## B. Quiz 模块补充

### B6 · 答题中途退出确认

- 弹窗标题 `Leave this quiz?`，正文 `Your progress in this level will be lost.`
- 按钮：`Stay`（主，关闭弹窗）、`Leave`（次，红色，退出并置 attempt 为 `ABANDONED`）。
- 浏览器 `beforeunload` 同样提示；小程序用 `onUnload` 无法拦截，改为「返回时弹窗确认」的自定义返回按钮。

### B7 · 关卡已解锁 / 已通关态（Levels Tab）

| 状态 | 卡片表现 | 点击 |
| --- | --- | --- |
| 锁定 | 灰锁图标 + `Level N`，底色 `#EDF3EF`，不可点（`cursor: not-allowed`） | 弹 tooltip `Complete Level N-1 with 90%+ to unlock` |
| 可挑战 | 无锁，绿色描边 + `Level N` + `Play →` | 弹报名/开始确认（若未报名先报名） |
| 已通过 | 绿色对勾 + `Level N` + `92% · 01:20`（正确率 + 用时） | 直接重玩（已付费期内免费） |
| 进行中（断线回来） | 橙色 `Resume` 角标 | 续答 |

### B8 · 答题结束最后一题

- 最后一题 `Continue` 文案改为 `Finish`；点击后二次确认 `Submit and finish?`（显示 `Answered 7/8`）。
- 若有未答题，提示 `You have 1 unanswered question`。

## C. Contest 模块补充

### C4 · 详情页按钮状态机（关键）

| 条件 | 按钮文案 | 状态 | 提示 |
| --- | --- | --- | --- |
| 未开始 & 未报名 | `Unlock Now` | 可点 | 弹报名框，报名后按钮变 `Coming Soon` |
| 未开始 & 已报名 | `Coming Soon` | 置灰 | 显示开始倒计时 `Starts in 2d 04:12:33` |
| 进行中 & 未报名 & 有名额 | `Unlock Now` | 可点 | 报名即进入答题 |
| 进行中 & 未报名 & 满员 | `Full` | 置灰 | `All spots are taken` |
| 进行中 & 已报名 & 未作答 | `Play Now` | 可点 | — |
| 进行中 & 已报名 & 已交卷 | `View Result` | 可点 | 跳 C8 |
| 已结束 & 已报名 | `View Result` | 可点 | 显示自己的名次与奖励 |
| 已结束 & 未报名 | `Ended` | 置灰 | `This contest has ended` |
| 余额不足（报名费>0） | `Unlock Now` | 置灰 | 红字 `Insufficient coins` + `Buy Coins` 链接 |

### C5 · 竞赛规则与条款

- 入口：详情页右侧「分享」旁的 `View Rules & Terms`、报名弹窗底部链接。
- 形态：全屏抽屉/独立页 `/contests/:id/rules`，富文本（后台维护），带「我已了解」关闭按钮。
- 必备条款：报名与退费（报名后不退）、计分（每题等分）、并列规则、发奖时间、防作弊（切屏≥3 次作废）、奖励发放形式（金币/XP，不可叠加）。

### C6 · Contest 答题页其它题型

| 题型 | 展示 | 提交 |
| --- | --- | --- |
| 单选 | 圆形单选 + 序号 + 文本 | Submit |
| 判断 | 两个选项 `True` / `False` | Submit |
| 填空（多个空） | 每个空一个下划线输入框，题干中标 `____` 位置 | Submit |
| 多选 | 方形复选框 + 顶部提示 `Answer can be one or more.` | Submit |

### C7 · Contest 交卷 / 断线恢复

- 交卷前弹确认：`Submit your answers? You answered 6/8 questions.` → `Submit` / `Keep playing`。
- 断线重连：进入答题页先查 `GET /contests/:id/attempt`，若存在未完成 attempt，弹 `Resume your contest?` → 恢复到当前题与剩余秒数。
- 超时自动交卷后展示 toast `Time is up, your answers have been submitted.`

### C8 · Contest 结果页（推荐设计）

**布局**：沿用 Quiz 结果页视觉（居中单列、浅绿背景）。

| 元素 | 内容 |
| --- | --- |
| 头像 + 昵称 | 当前用户 |
| 得分 | 大字 `7 / 8`（绿色） |
| 排名 | `Rank #12 of 609`，前三名加皇冠图标 |
| 用时 | `Total time 06:32` |
| 统计卡 | `Right Answer 7` / `Wrong Answer 1` / `Time 06:32` |
| 奖励 | `待竞赛结束发放` 或（已结算）`+1000 Coins · +10000 XP` |
| 操作 | `View Leaderboard`、`Preview Answers`、`Back to Contests` |

### C10 · 奖励到账反馈

- 站内通知：标题 `Contest reward received`，内容 `You ranked #2 in Web Development and earned 500 coins + 5000 XP.`
- 顶部金币数字滚动动画 + 右上 toast `+500 coins`。
- Coin History 新增一条 `CONTEST_REWARD` 记录，点击可跳竞赛详情。

## G. Games 四个游戏（推荐规则）

> 均为「每日一词」类轻量游戏，规则统一、界面差异化。奖励：每日首次通关 +10 金币，连续 7 天额外 +50。

### G1 · Wordling（每日猜词 · 标准）

- 5 个字母（英文单词）、6 次机会、每日 1 次免费。
- 界面：顶部 Logo + 日期；中部 6×5 方格网格；底部虚拟键盘（QWERTY）。
- 输入后提交，格子翻牌着色：绿色 = 字母与位置都对、黄色 = 字母对但位置错、灰色 = 不含。
- 状态：`IN_PROGRESS` / `WIN` / `LOSE`；结束后展示答案 + `Share`（生成 emoji 方块战绩图）+ 倒计时到明日。
- 失败可看激励视频/花 20 金币复活 1 次 `[推荐]`。

### G2 · Wordling Min / G3 · Wordling Max

- `Wordling Min`：**4 个字母 + 5 次机会**，词库更简单（初阶）。
- `Wordling Max`：**6 个字母 + 7 次机会**，词库更难。
- 其余同 G1；三个游戏各自独立计次与战绩。

### G4 · Hexling

- 六边形蜂窝棋盘（7 个六边形拼成的蜂窝，中心 1 + 周围 6）。
- 玩法：在棋盘上按相邻顺序连线拼出合法单词，单词长度 ≥3，字母可重复使用同格一次。
- 每局 90 秒或 10 个词，得分 = 单词长度²；每日 3 局。
- 界面：棋盘居中（字母随机分配，元音保底 2 个）、顶部计时与得分、底部「提交 / 清空」按钮、已找到单词列表。
- 结束后展示得分、排名、`分享`。

> 若需求方希望换成其它玩法（如数独、记忆翻牌、2048），只需替换 `games` 模块的规则实现，页面骨架与奖励体系复用。

### G5 · 游戏结果页

- 成功：`You got it!` + 答案 + `+10 coins` + 用时/次数 + `Share` + `Back to Home`。
- 失败：`Better luck tomorrow` + 正确答案 + `复活（20 金币）` / `分享`。
- 分享图：emoji 格子矩阵 + 品牌水印（小程序分享卡片同图）。

### G6 · 次数限制

- 达到当日上限：`You've played today. Come back in 05:12:44`，按钮置灰，附「明天提醒我」（订阅消息授权）。

### G7 · 游戏战绩

- `我的 → 游戏记录`：按日期列出四个游戏的胜负、用时、获得金币；总胜率统计。

## J. 法律与政策页

三个页面共用同一套「富文本 + 侧边目录」模板：`/privacy-policy`、`/legal-information`、`/confidentiality-privacy`。

- 布局：左侧目录（按 h2 自动生成，滚动高亮）+ 右侧富文本；顶部面包屑 + 最后更新日期。
- 内容由后台「站点配置 → 法律页」维护，支持中文/英文两套。
- 首版文案需法务提供；开发阶段先放占位（`内容待补充`），不影响联调。
